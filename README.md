## What is this?

[LeetCode](https://leetcode.com/) is a coding interview preparation platform featuring programming problems, database problems, contests and structured study plans.

This repository contains solutions to LeetCode problems across **SQL 50 Study Plan** and **Data Structures & Algorithms (DSA)** using **Python**.

---

## SQL 50

[LeetCode SQL 50](https://leetcode.com/studyplan/top-sql-50/) is a curated study plan containing **50 essential SQL questions** covering **basic-to-intermediate SQL topics** and designed for approximately **1 month of preparation**.

The study plan covers core SQL concepts including:

- Basic Queries
- Filtering
- Sorting
- Aggregate Functions
- `GROUP BY`
- `HAVING`
- `JOIN`
- Subqueries
- `CASE`
- NULL Handling
- Common Table Expressions
- Window Functions
- Ranking
- Data Transformation
